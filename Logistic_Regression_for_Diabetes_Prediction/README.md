This repository contains a collection of self-practice machine learning classification model implemented in Python using Scikit-learn. The project uses the Diabetes Classification dataset to predict whether a person is diabetic or not based on features such as Pregnancies, Glucose, BloodPressure, SkinThickness, Insulin, BMI, DiabetesPedigreeFunction, and Age. The target variable is Outcome (0 for non-diabetic, 1 for diabetic).



The model implemented in this project is Logistic Regression, used to predict diabetes based on medical parameters. The model achieved an accuracy score of 0.779 (77.9%) on the test dataset, providing a good baseline for binary classification. While the accuracy is reasonable, it suggests that the dataset may contain non-linear relationships that could be better captured by more complex models like Decision Tree or Random Forest in future work.
